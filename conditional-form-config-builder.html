Conditional Form Apex Provider Builder

Build an Apex form provider for conditionalRecordForm. Configure fields, sections, visibility, and value rules. The generated provider keeps Salesforce API names on the server and returns only logical field keys to the browser.

Form settings

Stored only in the generated Apex provider and never returned in the form JSON.
Optional. Set placeholders, validation messages, and help text by type or logical field key. See the README for examples.

Form items

Items are rendered in this order. Fields, sections, and text support built-in conditions or named custom evaluators.

Conditional value rules

Rules run after a controlling field or copy source changes. Copy can overwrite a target; clear writes null.

Generated Apex form provider

Add the generated Apex class to the allowlist in ConditionalRecordFormRegistry.

Apex provider output

Create a class named in the generated source, add a matching .cls-meta.xml file, and add the provider to ConditionalRecordFormRegistry. The provider owns both client-safe JSON and server-side field mappings.
